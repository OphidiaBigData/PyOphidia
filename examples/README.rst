PyOphidia Examples
==================

This folders contains some Jupyter Notebooks with examples of PyOphidia usage.

- The `basicExample.ipynb`_ notebook shows how to use the Cube module for performing a set of data analytics tasks: 
- The `workflowExample.ipynb`_ notebook shows how to use the Workflow and Experiments modules for running a data analytics workflow and extract its provenance

If CWL support is installed the notebook `cwlWorkflowExample.ipynb`_ under the `utils` folder shows an example of an Ophidia CWL-based workflow submission.

More examples and links to other material can be found in the documentation: `https://pyophidia.readthedocs.io/en/latest/index.html`_.
